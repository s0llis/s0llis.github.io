The Task

Build a to-do app in the spirit of Microsoft To-Do: users log in, create, edit and delete tasks, group them into categories, and find them with pagination, search and category filtering. The backend had to be a REST API on .NET with a relational database and a 4-layer architecture, and the frontend an Angular app styled with Tailwind or Bootstrap.

The Solution

A .NET REST API with a 4-layer architecture and an Angular frontend. JWT login with refresh tokens and user/admin roles, tasks with statuses and categories, server-side filtering and pagination, and debounced search. SQL Server runs in Docker, and migrations apply automatically.

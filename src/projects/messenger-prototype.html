The Task

Build a messenger backend for a university software engineering lab: users, direct and group conversations, and message history, plus a moderation system where messages can be reported and reviewed by admins and moderators.

The Solution

A Node.js REST API in TypeScript with Express and PostgreSQL. Zod validates requests, and RabbitMQ handles background processing so the API stays fast. Reports go through a claim, resolve or reject workflow. Everything runs in Docker, with tests in Jest.
